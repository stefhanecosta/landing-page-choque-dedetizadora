# Choque Dedetizadora

Site institucional da **Choque Dedetizadora**, empresa especializada em controle de pragas, atendendo São Luís - MA e região. O site apresenta os serviços oferecidos, diferenciais da empresa e um formulário para solicitação de orçamento.

## Acesse o site

[choque-dedetizadora.vercel.app](https://choque-dedetizadora.vercel.app) <!-- ajuste para sua URL real -->

## Sobre o projeto

Landing page desenvolvida para apresentar a Choque Dedetizadora de forma profissional, com foco em conversão de leads via WhatsApp e formulário de orçamento. O site é totalmente responsivo e inclui:

- Seção inicial com formulário de solicitação de orçamento
- Catálogo de serviços (dedetização, desratização, descupinização, limpeza de reservatórios, sanitização, laudos técnicos, consultoria e tratamentos preventivos)
- Seção "Sobre" com os diferenciais da empresa
- Processo de atendimento em 4 etapas
- Vitrine de clientes atendidos
- Botão flutuante de contato via WhatsApp
- Rodapé com informações de contato, redes sociais e área de atendimento

## Tecnologias utilizadas

- **HTML5**
- **CSS3**
- **JavaScript**
- [Font Awesome](https://fontawesome.com/) — ícones de redes sociais e contato
- [Lucide Icons](https://lucide.dev/) — ícones da seção de diferenciais
- [Vercel](https://vercel.com/) — hospedagem e deploy
- Google Analytics — métricas de acesso

## Rodando localmente

Por ser um site estático (HTML, CSS e JS puros), não há necessidade de instalação de dependências.

1. Clone o repositório
```bash
   git clone https://github.com/stefhanecosta/landing-page-choque-dedetizadora.git
```
2. Entre na pasta do projeto
```bash
   cd landing-page-choque-dedetizadora
```
3. Abra o arquivo `index.html` no navegador, ou use uma extensão como o **Live Server** (VS Code) para servir os arquivos localmente.

## Deploy

O deploy é feito automaticamente pela [Vercel](https://vercel.com/) a cada push na branch `main`. Branches criadas para novas features geram *Preview Deployments* automáticos para testes antes do merge.
